# Meu App Flask

## Como rodar localmente
```bash
pip install -r requirements.txt
python app.py
```

Acesse: http://127.0.0.1:5000/

## Como rodar no Render
1. Suba este projeto para o GitHub.
2. Vá até [Render](https://render.com/).
3. Clique em "New Web Service".
4. Conecte ao seu repositório e selecione a branch.
5. Render detectará o `Procfile` e criará a URL pública.
